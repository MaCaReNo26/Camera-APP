# Aplicación Cámara y Galería en Ionic

Aplicación móvil desarrollada con Ionic Framework y Angular que utiliza la cámara nativa del dispositivo para capturar fotografías, almacenarlas localmente en el sistema de archivos y gestionarlas dentro de una galería con opción de eliminación.

## Funcionalidades
- **Captura de Fotos:** Uso del plugin `@capacitor/camera` para tomar fotografías nativas.
- **Almacenamiento Local:** Persistencia de imágenes usando `@capacitor/filesystem` y registro de estado mediante `@capacitor/preferences`.
- **Galería Integrada:** Visualización en cuadrícula responsiva de todas las fotos capturadas.
- **Eliminar Fotos:** Menú de opciones de eliminación mediante `ActionSheetController`.

## Requisitos
- Node.js
- Ionic CLI (`npm install -g @ionic/cli`)
- Android Studio (para la compilación del APK nativo)
